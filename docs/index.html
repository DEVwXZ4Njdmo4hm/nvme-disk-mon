NVMe-Disk-Mon @NDM_VERSION@

Description

NVMe-Disk-Mon (NDM) is a long-running service that monitors host writes to configured NVMe devices, records historical statistics, attributes block writes to cgroup workloads, and sends threshold alerts by email.

Usage

nvme-disk-mon [option] [suboption]

Available Options

nvme-disk-mon
Run the monitoring daemon with the configuration installed at /etc/nvme-disk-mon/ndm-cfg.toml.
help
Show command help without reading the configuration.
-h, --help
Show the same command help through the standard option form.
version
Show the complete program version string without reading the configuration.
-V, --version
Show the same complete program version string through the standard option form.
stats
Show the program version, daemon status, and configured device status, including each label, serial number, latest sampled cumulative SMART write amount in GiB, its corresponding UTC sample time, and last anomaly time. Unavailable database values are shown as ------.
mail authorize
Complete interactive authorization for an XOAUTH2 or OAUTHBEARER mail account.
mail validate
Establish a fresh authenticated SMTP session and validate the credentials.
mail test-send
Submit one test message using the configured mail account.
